# Adapting title styles

Use this only when a new style or reference needs to be translated into an implementation. Keep a project's choices with that project; add a reusable recipe here only after it has been exercised and offers a distinct treatment.

## Common style vocabulary

| Decision | Record for each requested role |
| --- | --- |
| Purpose | Main statement, section heading, quotation, name/role, closing message |
| Typography | Available/licensed font and style, coverage fallback, relative scale, tracking, line spacing, alignment |
| Surface | Fill, opacity, shadow softness/offset, stroke or backing if requested |
| Placement | Safe margins, face exclusion, caption zone, bright/busy background cases |
| Motion | Entrance, readable hold, exit, easing; duration and time domain |
| Construction | Existing template or editable nodes, exposed controls, font/assets needed to reopen |
| Evidence | Which reference supports appearance, mechanics and motion; unverified details |

Keep role data separate from the construction. A new palette, font or motion treatment should not require copying the entire title workflow. Create only the roles needed for the current edit.

## Two starting approaches

**Quiet documentary:** clear type, restrained hierarchy, generous reading time and modest fades. Name/role text is smaller than main statements. Choose shadow, backing or neither from contrast over the actual shots, not a universal rule.

**Reference-led filmic treatment:** extract the reference's letter proportions, spacing, color, transparency and edge/shadow treatment independently. The large title can carry the distinctive treatment while names use a simpler related variation. A look LUT shown in a tutorial is a separate footage-grading decision, not part of the text style by default.

Neither approach fixes a font, gold color, blur radius, frame rate or LUT strength. For another style, reuse the decision table and title verification process; record only the new role choices and genuinely different construction.
