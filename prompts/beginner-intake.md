# Beginner video prompt

Copy this into your assistant. Everyday descriptions are enough; leave anything blank or say “please suggest.”

~~~text
Help me make a video in DaVinci Resolve. I'm new to editing; handle the
technical choices for me.

Before editing, help me get ready:
1. Read the setup instructions at
   https://github.com/amartinez1558/davinci-workflow-skills
   Check whether these skills are installed, enabled and available in this
   assistant. Reuse an existing installation; otherwise help me install
   from the repo using the supported steps for my assistant. Clone only
   if needed, without overwriting existing work. If a new chat or restart
   is required, explain how to resume and verify the skills are available.
2. Confirm DaVinci Resolve is open with the project I intend to use.
   If I haven't started a project, help me create one.
3. Confirm the AI editing connection works. If setup is missing, guide me
   through File > Setup AI Assistants... or my version's equivalent.
   Verify the connection with a read-only check and tell me the project
   name and selected timeline, if one exists. Installed skills alone don't
   establish a working Resolve connection. Don't edit until setup is ready.

My video is about:
My videos, photos, script or recordings are here:
Who will watch it, and where (for example, on a phone or a big screen):
Rough length and deadline, if I have them:
Things to include or avoid; a style example, if I have one:

Use these defaults unless I ask otherwise: one edited video, a natural
look, a clear story, simple titles, readable spoken captions and clear
voices. Add quiet music only if I supply music I can use.

Inspect the material and suggest a length and suitable sharing settings.
Keep an existing project's settings unless a change is needed and explained.
Preserve my originals and previous edits; save a new version.

Check access to my files and give me a short plan.
Ask up to three plain-language questions at a time
only when needed, with suggested answers. Don't make me choose technical
settings.

Don't guess people's identities or use unrelated footage as a real event.
Explain missing material and suggest alternatives. Ask before deleting,
buying/downloading extra material or sharing outside my project.

Use the DaVinci workflow skills. Check the sharing copy, save it alongside
the project, and tell me where it is and what still needs my review.
~~~
