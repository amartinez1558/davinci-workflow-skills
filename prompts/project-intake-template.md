# Advanced project intake

For a simpler start, use the [beginner prompt](beginner-intake.md). This version is for projects needing detailed control. Copy and fill what you know; leave unknown fields blank.

~~~text
Use the DaVinci workflow skills to complete this video project.

Goal/audience/platform:
Deliverable: [separate smaller clips / one film / both]
Runtime/deadline:
Style/references and pacing:
Project name/root and open timeline:
New edit or revision? Reviewed version and feedback link/file:
Recent manual changes to preserve:
Authoritative script CSV/Sheet and media map:
Media roots/intake links and confirmed people/roles:
External recordings/takes/channels:
Camera formats/profiles, baked grades, licensed LUT:
Timeline rate, resolution/aspect and output color space:
Caption mode/language: [editable / burned / sidecar / none]
Names/years/titles, intro/outro and approved quotations:
Music source/license and mixing guidance:
True-peak ceiling and any loudness standard:
Missing assets, acceptable alternatives and placeholders:
Dropbox account/root, free space and working storage/reserve:
Output path, sharing/size goal and cloud destination:
Resolve version/edition, AI Assistant connection and tools:
Boundaries: source-sheet edits, downloads, cleanup:

Inspect supplied sources and the live project first. Summarize known facts
and the smallest complete plan. Ask concise grouped questions only for
missing decisions materially affecting the result:
1. Which deliverable, audience, runtime, frame rate and format?
2. Which script, takes, identities and text are authoritative?
3. Which style, pacing, music, captions and placeholders?
4. Which storage budget, cloud destination and permitted operations?

Do not re-ask answered questions. Offer reversible defaults for ordinary
choices; never guess identities, provenance or permission. Continue useful
read-only preparation while waiting, but wait on dependent work.

Preserve live manual edits and originals. Maintain a plan, source/proxy
map, version-relative request audit and .drp/.drt milestones. Use Media,
Edit/B-roll, Fusion, Color, Fairlight, Export and Dropbox as needed.
Inspect tool support rather than inventing calls; request native
intervention only where necessary.

Check application state and, when export is requested, the encoded file.
Report paths/version/settings, checks, missing assets, cloud status and
review limits. A successful call, local file, still or decode does not
establish full approval of a finished film.
~~~
